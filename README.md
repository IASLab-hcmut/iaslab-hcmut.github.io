# Intelligent Autonomous Systems Lab — website

Static website (HTML/CSS/JS, no build step) for GitHub Pages.

## Deploy to `<username>.github.io`
1. Create a public repo named exactly `<username>.github.io` on GitHub.
2. Push this folder to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch*, `main` / `/ (root)`.
4. Site is live at `https://<username>.github.io` within ~1 minute.

## Editing
- Pages: `index.html`, `research.html`, `people.html`, `publications.html`, `join.html`
- Header / footer / illustrations: `assets/main.js`
- Colors & layout: `assets/style.css`
- Replace the "KH" avatar in `people.html` with `<img src="assets/hieu.jpg">` when you have a photo.
